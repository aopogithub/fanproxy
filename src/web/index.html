      勾选「启用 HTTPS」后保存，fanproxy 会先让站点以 HTTP 生效完成 ACME 校验，再调用 certbot 签发证书并自动切换 HTTPS + 80 跳转；本地已有证书则直接复用。取消勾选并保存会释放 certbot 管理的证书路径，那张证书随即变为「未关联」、可以在证书页删除。
      
              
      勾选「关闭 HTTP」后该站点不再监听 80 端口（只保留 HTTPS，适合做安全加固）。证书签发与自动续期需要 80 端口做 ACME 校验，fanproxy 会在续期时临时放通、续期完立刻撤掉，所以域名仍需解析到本机；如果有证书但签发时间较久，请注意续期窗口。
